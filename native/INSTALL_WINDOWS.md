# Что делать с IPA на Windows

Эта инструкция применяется **после успешной облачной сборки**. Компиляция и установка — отдельные проверки; текущий форк ещё не проверен на телефоне клиента.

1. Скачать артефакт **Telegram-iPhone-IPA-needs-signing** со страницы успешного запуска GitHub Actions и распаковать ZIP. Нужен файл `Telegram.ipa`, а не архив исходников.
2. Установить [Sideloadly](https://sideloadly.io/). Его сайт указывает необходимость web-версий iTunes и iCloud для Windows; ссылки находятся там же.
3. Подключить iPhone кабелем, разблокировать и подтвердить доверие компьютеру.
4. Выбрать телефон в Sideloadly, перетащить IPA и использовать свой Apple ID. Пароль и коды входа вводятся владельцем на его компьютере, не в репозитории и не в переписке.
5. Запустить установку. Выполнить требуемые iOS подтверждения доверия и включения Developer Mode, если система их запросит.
6. Проверить запуск, создание локальной переписки, редактор, сохранение после перезапуска. Только после этого считать установку подтверждённой.

С бесплатным аккаунтом подпись действует 7 дней; Sideloadly поддерживает автоматическое обновление при доступном компьютере. Удалять приложение каждую неделю не требуется. При обновлениях сохранять тот же идентификатор приложения и заранее экспортировать резервную копию. [Источник: Sideloadly](https://sideloadly.io/).

При ошибке установки нужен её точный текст. При вылете после запуска нужен crash log: это может быть отдельной проблемой возможностей App Groups/Keychain, которую успешная компиляция не проверяет.
