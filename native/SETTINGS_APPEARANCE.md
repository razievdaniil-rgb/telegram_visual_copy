# Настройки: аватар или шестерёнка

Для обычной установки выбран аватар владельца. Кнопка открывает исходный `PeerInfoScreenImpl(isSettings: true)`. Фото берётся из того же профиля, что и публичный экран настроек; аватар собеседника не используется. Нижняя отдельная лупа отключена. Геометрия компактного заголовка и его прокрутки сохранена.

## Как вернуть шестерёнку

В `native/Sources/Core/SimulatorUIConfiguration.swift` изменить только:

```swift
public static let defaultSettingsTabAvatar = false
```

Затем собрать новый IPA. При `false` сигнал `accountTabBarAvatar` возвращает `nil`, а исходный код Telegram использует `Chat List/Tabs/IconSettings` (или свою сезонную иконку), штатную анимацию TabSettings и отключает кольцо выбора аватара. Контроллер настроек не меняется. Обе ветви входят в одну компиляцию, отдельные изображения шестерёнки и копия экрана не добавлены. Тест использует фактическое значение default и не требует переписывания при его смене.

Для проверки без повторной компиляции есть предпочтение запуска `TelegramSimulator.settingsTabAvatar`. Maestro передаёт `false` или `true` через `launchApp.arguments`. Обычная установка не передаёт этот аргумент и следует default. QA запускает обе ветви на одном бинарнике и сохраняет отдельные снимки; визуальное принятие отмечается только после просмотра этих снимков.

Вне локального режима сохраняется оригинальное правило Telegram: аватар при нескольких аккаунтах, шестерёнка при одном. Локальное предпочтение не меняет онлайн-ветвь.

## Хранение при установке через Sideloadly

Локальная сборка без расширений использует собственный контейнер приложения для Postbox и исходный путь документа версии 1. Для запуска не требуется общий контейнер App Groups. В обычном, нелокальном режиме остаётся исходный App Groups-контейнер и его проверка. Формат документа и поля профилей не меняются.

Переход с прежней тестовой сборки может заново создать производный Postbox в собственном контейнере; профили и переписки восстанавливаются из локального документа. Отдельные предпочтения прежнего Postbox, например папки, не входят в этот документ. Перед обновлением следует экспортировать резервную копию. Сохранение после настоящей переподписи проверяется на iPhone отдельно.
