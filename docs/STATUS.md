- Список чатов с поиском, превью, временем, фильтром и счётчиком непрочитанных.

- Ручные статусы «в сети», «был(а) недавно», анимированное «печатает…» с учётом уменьшения движения.
- Уменьшение аватаров до 320×320, сохранение локальных данных частями, последовательная запись с сохранением предыдущего снимка при ошибке.

Следом перенести стеклянные панели, оригинальные иконки, фон, хвостики и расположение времени; найти подходящий референс профиля. Пиксельное совпадение ещё не подтверждено. Иконка приложения пока из шаблона Expo.
2. Запустить нативные workflow, получить APK/IPA и исправить возможные проблемы сборки. Сейчас готовых нативных бинарников нет. Локально отсутствуют Android SDK и macOS/Xcode.
3. Проверить на реальном iPhone и Android: системные отступы, клавиатуру, переносы длинного текста, галерею, жест входа, перезапуск приложения и установку через выбранный способ подписи.
4. Подготовить демонстрационную запись и инструкцию для заказчика.
5. Разобрать предупреждения зависимостей: последняя установка сообщила о 21 уязвимости (3 moderate, 18 high) в дереве зависимостей. В том числе есть upstream-предупреждения `braces` и `node-forge`; исправленные версии этих двух пакетов на момент проверки в npm отсутствовали. Принудительное понижение Expo до несовместимой версии не применялось.

Переписки и профили остаются локальными. Экспорт переписок и облачная копия в текущий объём не входят.
