# Проверка ТЗ нативного Telegram — 27 октября 2026

Эталон: Telegram iOS **13.1.1**, исходники `fb0e62ba8a147f0821da6aa63c09da7d79a10111`. Проверяется нативный UIKit/Texture-форк. Архивные Expo/PWA-проверки не подтверждают его работу.

## Проверка до исправлений

[Запуск 40508359440](https://github.com/razievdaniil-rgb/telegram_visual_copy/actions/runs/40508359440), бинарник `2e15eea`, отдельный iPhone 13 Pro Max / iOS 27.0. Публичный сценарий прошёл, три снимка просмотрены. [Архив снимков и видео](https://github.com/razievdaniil-rgb/telegram_visual_copy/actions/runs/40508359440/artifacts/12735679224), SHA-256 `bdcb2958869a8439fac93e043cc4c418ce22f932a6abc0c2b03424511295da6f`. Контактный лист получен из PTS ffprobe и просмотрен.

Снимки сохранены и в истории Git: [список](screenshots/native-qa-before-chats.png), [диалог](screenshots/native-qa-before-dialogue.png), [профиль](screenshots/native-qa-before-profile.png). Разрешение 1284×2778, ширина интерфейса 428 pt при scale 3. Это исходное состояние до текущих исправлений.

- Список показывает имена, инициалы вместо отсутствующего аватара, превью, время и счётчик.
- Диалог показывает оба направления, многострочный русский текст, emoji, время и две галочки.
- **Ошибка:** порядок сообщений нарушен: 12:57 перед 12:56, 12:59 перед 12:58. Индекс истории и диапазоны чтения Postbox используют Cloud ID и предполагают их монотонность; хешированные ID её нарушают. Сам оператор сравнения `MessageIndex` при этом сравнивает сначала timestamp — проблема не в его замене или геометрии пузырей.
- Профиль открывается, имя/фамилия, статус и описание видимы. Номер, username и фото в старом примере не заданы — эти поля этим сценарием не проверялись.
- Английские подписи и `online` — русский языковой пакет не был загружен в офлайн-аккаунт.
- Отдельная проверка редактора **не дошла до команд сценария**: второй запуск XCTest/Maestro завис при старте. Это ограничение диагностики, а не доказательство успешного входа.
- Дополнительно чтением исходников найдена **гарантированная ошибка открытия редактора**: `Display.NavigationController.present(_:animated:)` вызывает `preconditionFailure()`. Этот метод также ошибочно использовался для уведомления о неудачной записи.

## Исправления

- `f43362f`: редактор и уведомления открываются через оригинальный `applicationBindings.presentNativeController`; область жеста учитывает safe area окна. У редактора появились идентификаторы доступности для автоматизации; в выборе даты установлен допустимый диапазон Telegram.
- Сообщения обновляются в Postbox без удаления всей истории при каждой отправке/правке: сохраняются строки и стабильные идентификаторы анимаций.
- `302f6fe`: производные Cloud ID возрастают по времени внутри диалога; исходные JSON ID и формат v1 сохранены. Для сохранения идентичности пузырей используется `customStableId` из исходного ID. Перестановка при изменении даты корректирует проекцию; обычное добавление в конец сохраняет предыдущие ID.
- Официальные [русские строки Telegram iOS](https://translations.telegram.org/ru/ios/) встроены локально из экспорта от 27 октября. Исходный `.strings`, генератор и SHA-256 сохранены. Сетевой запрос языкового пакета не требуется; английский остаётся оригинальным fallback отсутствующих ключей.
- Новый тестовый документ содержит PNG-аватар, фамилию, username, вымышленный телефон, описание, разные дни, одну/две галочки. Создаётся только в новом CI-симуляторе.

## Ожидания для визуального прохода

Системный SF с настоящими начертаниями; исходные маски/хвостики/галочки Telegram. Текст использует доступную ширину, время не перекрывает последнюю строку. Сообщения идут по возрастанию заданного времени, соседние группируются по оригинальным правилам. Дни разделены нативной плашкой. Аватар одинаков в списке, заголовке и профиле. Статус меняется после сохранения, «печатает» использует исходную анимацию Telegram. При переходе между списком/диалогом/профилем нет белой щели, повторного появления пузырей или скачка неподвижного соседнего элемента. При отправке/правке история целиком не исчезает. Кнопки редактора отсутствуют до скрытого жеста.

Размеры и кривые анимаций публичного интерфейса не заменены собственными: используются исходные компоненты. Но для заявления о полном совпадении нужна сверка с соответствующим экраном оригинального приложения на той же системе, с одинаковыми данными, локалью и размером текста. Такой парной записи пока нет. Физический iPhone и установка обновлённого IPA также не проверены.

[Аудит исходных UI-файлов](builds/native-ui-source-audit.json): 13 файлов шрифтов, навигации, вкладок, списка, диалога, заголовка, текста, пузырей, времени/галочек, ввода, профиля и темы совпадают с pinned upstream после нормализации переносов строк. Это проверка реализации, а не визуальная приёмка.
