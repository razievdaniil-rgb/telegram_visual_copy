## Общие параметры

- Рабочая ширина 402 pt; полный экран макета 402×874. Системная строка высотой 62 pt удаляется из сравнения web: её отображает ОС.
- Строка чата 78 pt, аватар 62 pt, отступы слева 10, справа 16, промежуток 10.
- Основной текст 17/22 с tracking −0.43; превью 15/20 −0.23; подпись 13/18 −0.08; имя в профиле 28/34 bold.
- Акцент `#008BFF`, исходящий пузырь `#EFFEDD`, групповой фон `#F2F2F7`, разделитель `#E6E6E6`, профиль `#4890BF`.
- Пузырь: радиус 18, максимальная ширина 288, отступы 9/5. Форма хвоста и обои экспортированы из оригинала.
- Круглые кнопки заголовка 44; composer 42; нижняя капсула и поиск 62. Нижнее положение учитывает системный safe area.

Тема находится в `src/theme.ts`. На iOS используется системный SF; web и Android используют доступный системный шрифт. Вес 510/590 приближен к 500/600.

## Ресурсы и стекло

Оригинальные SVG и шрифт символов сохранены в `assets/telegram/`; происхождение описано в его README. Соответствие кодов символов взято из контекстов Figma. Для системных chevron/magnifyingglass/xmark на iOS используется SF Symbols через Expo Symbols.

На поддерживаемой iOS 26+ используется Expo GlassView с проверкой доступности. На старых iOS, Android и web — BlurView и полупрозрачная поверхность той же геометрии. Уменьшение прозрачности на iOS включает непрозрачную поверхность. Внешний вид стекла на физическом iPhone ещё требует проверки.

Данные аватаров, имён, телефонов и переписок берутся из локального хранилища. Демонстрационные каналы, медиа, музыка, истории и premium-декорации из макетов не подставляются вместо пользовательских данных. Кнопки вне объёма текстового симулятора показывают уведомление о недоступности. Вкладка звонков содержит пустое состояние; отдельного эталона пустого экрана в наборе не зафиксировано.

## Репозитории Telegram

[telegramdesktop/tdesktop](https://github.com/telegramdesktop/tdesktop), присланный пользователем, содержит настольный клиент. [TelegramMessenger/Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) служит дополнительным справочником iOS. Их исходники не переносились как готовые React Native-компоненты. Приложение остаётся на Expo + Expo Router, без сервера и подключения к Telegram.
