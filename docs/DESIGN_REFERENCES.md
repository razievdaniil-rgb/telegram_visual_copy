## Репозитории Telegram

- Предоставленный пользователем [telegramdesktop/tdesktop](https://github.com/telegramdesktop/tdesktop) содержит настольный клиент для Windows, macOS и Linux. Использовать как дополнительный справочник; оформление iOS по нему не определять.
- [TelegramMessenger/Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) — исходники клиента iOS; более подходящий справочник для поведения и нативного оформления.

Проект остаётся на React Native + Expo. Исходники интерфейса настольного или iOS-клиента не являются готовыми React Native-компонентами.
