# План на пять дней

1. Основа Expo + TypeScript, модель профилей/чатов/сообщений, локальное хранение, рабочие переходы между экранами.
2. Публичный интерфейс: список, диалог, профиль; разделители дат, галочки и статусы.
3. Скрытый редактор: профили, аватары, обе стороны переписки, дата/время, статусы, редактирование.
4. Проверка сценариев и восстановления данных; визуальная сверка с согласованными скриншотами Telegram iOS; проверка клавиатуры и safe areas на устройствах.
5. Исправления после демонстрации, Android APK, iOS IPA, проверка установки на iPhone заказчика, передача исходников и инструкции.

## Критерии приёмки

- Создать профиль, чат, входящее и исходящее сообщение с разными датами.
- Изменить имя/номер/аватар; увидеть изменения в списке, диалоге и профиле.
- Изменить текст, сторону, время, галочки существующего сообщения.
- Включить каждый статус; «печатает…» анимируется.
- Список сортируется по последнему сообщению, сообщения — по заданному времени.
- Перезапустить приложение: данные сохранены.
- Открытие чата сбрасывает счётчик непрочитанных.
- На публичных экранах нет элементов скрытого редактора.
- Пройти сценарии на Android и реальном iPhone; видео web-превью не заменяет проверку на устройстве.

## Технические решения

React Native + Expo, системный шрифт (SF на iOS), светлая палитра iOS Telegram, TypeScript. AsyncStorage для локального документа с версией схемы. Аватары сохраняются как локальные data URI, чтобы не зависеть от временных файлов галереи. Логика состояния отделена от экранов и проверяется unit-тестами. Данные не отправляются в Telegram.

Исходники Telegram iOS используются как дополнительный справочник и не переносятся в приложение. Оформление реализовано по пяти зафиксированным экранам присланного UI Kit; оригинальные графические ресурсы и шрифт набора включены локально. [Источники](DESIGN_REFERENCES.md) и [визуальная сверка](VISUAL_QA.md) описаны отдельно. Приёмка на физических устройствах ещё требуется.
