TELEGRAM — УСТАНОВКА НА IPHONE

Файл: Telegram-client.ipa
Версия: 13.1.1, сборка 12.
Вкладка «Настройки» использует стандартную шестерёнку Telegram.

УСТАНОВКА

1. Скачайте Sideloadly с официального сайта https://sideloadly.io/ на Windows или Mac. На Windows установите компоненты Apple по ссылкам на этом же сайте.
2. Подключите разблокированный iPhone к компьютеру кабелем и подтвердите доверие компьютеру.
3. Откройте Sideloadly, выберите свой iPhone, перетащите файл Telegram-client.ipa и выполните подпись и установку со своим Apple ID.
4. Выполните запрошенные iOS подтверждения доверия разработчику и режима разработчика, если они появятся.
5. Откройте установленное приложение. Установка простым открытием IPA в Telegram не выполняется. Настоящий Telegram удалять не нужно; вход по номеру телефона и код SMS здесь не требуются.

ПЕРВЫЙ ЗАПУСК

Приложение запускается с пустым списком чатов. Переписки создаются вручную.

Удерживайте верхний заголовок «Чаты» 1–2 секунды, чтобы открыть скрытый редактор.
В разделе «Мой профиль» задайте своё имя и аватар.
Нажмите «Добавить собеседника», заполните имя, фамилию, username, телефон, описание и выберите фотографию. Сохраните профиль.
Нажмите «Создать чат», выберите собеседника и нажмите «Готово» для выхода из редактора.

РАБОТА С ПЕРЕПИСКОЙ

В обычном диалоге поле ввода отправляет сообщения от вашего лица. Для публичного редактирования исходящего сообщения удерживайте его и выберите «Изменить».
В скрытом редакторе откройте нужную переписку: здесь можно добавлять сообщения за любую сторону, изменять текст, дату, время, галочки, статус собеседника и счётчик непрочитанных.
Данные профиля и аватар меняются в редакторе профилей. Собственное фото отображается в экране настроек; иконка вкладки остаётся шестерёнкой.

ОБОИ

Общий фон меняется через «Настройки» → «Оформление» → «Обои для чатов». Доступны локальные варианты узора и цвета. Для возвращения стандартного фона используйте «Сбросить настройки обоев».

СОХРАНЕНИЕ И ОБНОВЛЕНИЕ

Переписки сохраняются на устройстве. Для резервной копии используйте экспорт JSON в скрытом редакторе, особенно перед обновлением приложения. Экспорт содержит профили и переписки, но не настройки обоев и фоновые фотографии. Удаление приложения удаляет локальные данные.
При бесплатной подписи её необходимо обновлять каждые 7 дней; Sideloadly поддерживает автоматическое обновление подписи. Для повторной установки используйте тот же Apple ID и те же настройки подписи.
Если установка выдаст ошибку, сохраните её точный текст.
